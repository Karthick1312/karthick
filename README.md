### iRA – Smart Preventive Care

A React Native application that connects to compatible smart rings and displays wellness and activity data.

**Key areas of work:**
- Bluetooth device discovery, connection, and synchronization
- Native Android/Kotlin SDK integration
- Health and activity history with local persistence
- Cross-platform UI development and debugging
- Android and iOS build and release workflows
